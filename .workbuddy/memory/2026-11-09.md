## 搭建 product-ai（Cloudflare 商品知识库与对话推荐）

- 技术栈：Hono Worker + Workers AI + Vectorize + Hyperdrive(PostgreSQL) + 静态前端 `public/`，前端随 Worker assets 一起部署。
- 模型与索引：`@cf/baai/bge-m3`（1024 维 / cosine，中文友好），索引 `product-catalog`，namespace 分 `sku` / `kb`；生成模型 `@cf/meta/llama-3.3-70b-instruct-fp8-fast`，集中在 `src/config.ts` 可切换。
- 数据源 `docs/SKU_collation.json`：5985 SKU / 4853 SPU / 247 类目 / 244 供应商；「商品名称」大量是与商品无关的散文，因此向量文本把类目置顶并重复加权；重量/体积/简介字段 100% 为空；轮播图/阶梯价/物流是字符串内嵌 JSON，需 parseJson。
- 关键决策：
  - `postgres.js` 锁 3.4.x（官方 Hyperdrive 文档验证的版本；4.x 改了 `sql.unsafe` 参数签名）。
  - Vectorize metadata 索引必须在写入向量前创建；批量写入用 `jsonb_to_recordset` + `ON CONFLICT DO UPDATE`。
  - 幂等靠 `content_hash + synced_at`：先读旧 hash 再 upsert，失败批重跑自动重新向量化。
  - 检索用 RRF(1/(60+rank)) 融合关键词 ILIKE 与向量召回；对话推荐注入 SKU + 知识库上下文，LLM 只准引用 `[n]` 编号，生成失败降级为检索结果直答。
  - 登录用 PBKDF2 + HMAC-SHA256 JWT + HttpOnly Cookie；管理接口用 ADMIN\_TOKEN。
- 验证：`npx tsc --noEmit`、`node --check`（脚本/前端）、`npx wrangler deploy --dry-run` 全通过（210 KB / gzip 54 KB）；5985 条真实数据规范化零异常，embed 文本 119–331 字。
- 待用户提供：PostgreSQL 连接串 → 创建 Hyperdrive → 回填 `wrangler.jsonc` 的 `hyperdrive[0].id`；secrets（JWT\_SECRET / ADMIN\_TOKEN / ADMIN\_EMAIL / ADMIN\_PASSWORD）。
