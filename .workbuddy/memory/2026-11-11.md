## AI Gateway 接入决策

- 决策：保留 `env.AI.run()` 作为唯一模型入口，通过第三个参数注入 `AI_GATEWAY_ID`，不在 Worker 中持有 Cloudflare API Token。
- 缓存：聊天和意图识别显式跳过缓存；仅管理端 SKU 向量化和知识库构建使用 `SHA-256(模型 + 输入文本)` 作为内容寻址缓存键，TTL 为 7 天；用户检索向量不缓存。
- 隐私：网关控制台必须配置为仅存储日志元数据，代码只发送 operation/source/cache 三项非敏感元数据。
- 验证：2026-11-11 已通过 `npm test`、`npm run typecheck`、`npm run lint`、`npm run agent:check`、`npm run agent:guard`。
